## 📝 Project Overview

This project aims to apply data mining techniques to solve a real-world problem using one of three provided datasets. You will prepare data, apply predictive models (Decision Tree & Naïve Bayes), compare results, and generate actionable business recommendations.

---

## 📁 Available Datasets

Choose **one** of the following:

### 1. 📞 Churn Dataset
Objective: Predict customer churn (whether a customer will leave the company).

- Attributes: 21 (e.g., account length, number of calls, charges)
- Class Attribute: `Churn` (True/False)

### 2. 🏦 Bank Marketing Dataset
Objective: Predict whether a customer will subscribe to a long-term deposit.

- Attributes: 17 (e.g., age, job, marital status, duration, previous campaigns)
- Class Attribute: `Y` (yes/no)

### 3. 💳 Credit Card Dataset
Objective: Predict whether a credit applicant is a good or bad credit risk.

- Attributes: 20 (e.g., balance, credit history, savings, age)
- Class Attribute: `Creditability` (1 = Good, 0 = Bad)

---

## ⚙️ Steps to Follow

### 1. Data Preparation
- Understand data types (nominal, ordinal, quantitative)
- Handle missing values and outliers
- Normalize or discretize attributes
- Visualize distributions (e.g., histograms, box plots)
- Analyze correlations and balance in class distribution

### 2. Predictive Modeling
Apply and compare:

- **Decision Tree**
- **Naïve Bayes**

#### Requirements:
- Choose one validation strategy (e.g., train/test split or 10-fold CV)
- Compare models using:
  - Accuracy
  - True Positive / False Positive
- Interpret results: feature importance, decision paths, etc.

### 3. Compare Models
- Build baseline models with all features
- Build models with selected features
- Evaluate both approaches using the same metrics

### 4. Conclusion & Recommendation
- Summarize key findings
- Provide actionable recommendations for the business
